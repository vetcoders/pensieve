Writing surface

Write in Markdown, read it rendered.

You edit the Markdown source; Pensieve adds the rest — project search, live preview, backlinks, tabs, and sharing. Exports cover HTML, PDF, and Word DOCX; Word and text-based PDF documents come back as editable Markdown drafts without changing the originals.

Release 0.4.1

What’s new.

Windows

Files open as tabs

Files opened from Finder, the Dock, or open now land as native tabs in the frontmost window — honoring the system “Prefer tabs” setting instead of scattering standalone windows.

Speed

Find without the beachball

Find highlighting on large documents runs in a single text transaction. Thousands of matches no longer stall the editor on every keystroke.

Recovery

Drafts stay in their lane

A crash-recovery draft is restored exactly once, into the restored workspace window — it no longer hijacks new documents or multiplies across windows.
