Writing surface

Write in Markdown, read it rendered.

You edit the Markdown source; Pensieve adds the rest — project search, live preview, backlinks, tabs, and sharing. Exports cover HTML, PDF, and Word DOCX; Word and text-based PDF documents come back as editable Markdown drafts without changing the originals.

What’s new.

Voice

Dictation, on your Mac

A local dictation panel with automatic, Polish, and English recognition. The transcript assembles as you speak and lands at your cursor, aware of the current selection.

AI

Autocomplete from your provider

Inline completion backed by your own OpenAI or Anthropic endpoint: pick a model from live discovery, bring an API key, and it stays in the macOS Keychain. The completion continues your document — it doesn’t answer it like chat.

Workspace

Big workspaces stay fluid

Scans run off the main thread, deep folder changes reach the sidebar the moment they happen, and Trash is immediate — the tree changes only after the file is actually recycled.
