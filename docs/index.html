Pensieve

A fast, native macOS markdown editor for structured thought.

Focus First

Pensieve is built with native macOS primitives to be incredibly fast and lightweight. It strips away the noise, leaving you with pure text and a distraction-free writing environment. The aesthetic is heavily inspired by the source-first purity of iA Writer.

Features

  • Native Performance: Written in Swift, avoiding Electron bloat.
  • Source-First Identity: Focus on the markdown source, not a heavy WYSIWYG facade.
  • Local First: Your files stay on your machine. No cloud lock-in.
  • Agent-Aware Workflows: Current-document dispatch and Vista-powered autocomplete are wired into the editor.
  • Dark Mode Support: Seamless integration with macOS system themes.

Get Started

You can build Pensieve directly from source while the public distribution lane is being finalized.

git clone https://github.com/vetcoders/pensieve.git
cd pensieve
make build
make run

The local install lane is make install-app. The Mac App Store lane exists, but submission and signing remain operator-gated.
